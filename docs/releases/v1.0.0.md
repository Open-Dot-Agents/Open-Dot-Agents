# Open-Dot-Agents v1.0.0

Open-Dot-Agents v1.0.0 establishes the first stable portable `.agents/`
standard and reference CLI release.

## Included

- Normative 1.0 specification for repository-scoped `.agents/` configuration.
- Manifest and MCP JSON Schemas.
- Conformance fixtures and a standard-library conformance runner.
- Reference `agents` CLI for initialization, validation, capability reporting,
  import, export, conversion, and release artifact version reporting.
- Experimental Workbench projection fixtures for adapter research.
- Public governance, security, contribution, migration, compatibility, and
  release documentation.

## Reference CLI Assets

The release includes unsigned reference CLI archives and matching SHA-256
checksum files for:

| Platform | Archive |
| --- | --- |
| Linux amd64 | `agents-linux-amd64.tar.gz` |
| Linux arm64 | `agents-linux-arm64.tar.gz` |
| macOS amd64 | `agents-darwin-amd64.tar.gz` |
| macOS arm64 | `agents-darwin-arm64.tar.gz` |
| Windows amd64 | `agents-windows-amd64.zip` |
| Windows arm64 | `agents-windows-arm64.zip` |

Verify each archive with its matching `.sha256` file before use.

## Compatibility

No native harness adapter is conformance-supported in v1.0.0. The reference
CLI can project configuration for current targets, but adapter support remains
conservative until a version-pinned native black-box harness run proves
instruction discovery, MCP discovery/startup, skill discovery, precedence,
trust behavior, and known lossy behavior.

See [`COMPATIBILITY.md`](../COMPATIBILITY.md) for current claims and
[`VENDOR_EVIDENCE.md`](../VENDOR_EVIDENCE.md) for mapping evidence.

## Supply Chain Notes

The v1.0.0 assets are not signed and do not include SBOM or provenance
attestations. Do not claim signatures, SBOMs, provenance, package-manager
publication, or native harness support for this release.
