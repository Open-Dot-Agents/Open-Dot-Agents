# Open-Dot-Agents v1.0.0

This is a preparation draft for the first stable portable `.agents/`
standard and reference CLI release. Publication remains blocked by native
conformance and evidence requirements.

## Included

- Normative 1.0 specification for repository-scoped `.agents/` configuration.
- Manifest and MCP JSON Schemas.
- Conformance fixtures and a standard-library conformance runner.
- Reference `agents` CLI for initialization, validation, capability reporting,
  import, non-mutating plans, owned application, and artifact version reporting.
- Experimental Workbench projection fixtures for adapter research.
- Public governance, security, contribution, migration, compatibility, and
  release documentation.

## Reference CLI Assets

The release includes reference CLI archives, matching SHA-256 checksum files,
SPDX JSON SBOMs, and GitHub artifact attestations for:

| Platform | Archive |
| --- | --- |
| Linux amd64 | `agents-linux-amd64.tar.gz` |
| Linux arm64 | `agents-linux-arm64.tar.gz` |
| macOS amd64 | `agents-darwin-amd64.tar.gz` |
| macOS arm64 | `agents-darwin-arm64.tar.gz` |
| Windows amd64 | `agents-windows-amd64.zip` |
| Windows arm64 | `agents-windows-arm64.zip` |

Verify each archive with its matching `.sha256` file before use.

## Compatibility

No native adapter is currently conformance-supported. This draft must not be
published in that state. All three pinned adapters must satisfy the existing
support policy, including public evidence, before the root 1.0.0 release.
The new refusal checks preserve explicit limitations; they do not establish
full native support.

See [`COMPATIBILITY.md`](../COMPATIBILITY.md) for current claims and
[`VENDOR_EVIDENCE.md`](../VENDOR_EVIDENCE.md) for mapping evidence.

## Supply Chain Notes

Verify checksums and GitHub attestations before use. The release does not imply
package-manager publication or support for an unlisted harness version.

- The `Verify` and `Security` workflows passed for the release commit.
- All three adapter rows are supported and link durable, verified evidence.
- Baseline and extended native evidence passed for the exact release sources.
- The `Release candidate` workflow passed for the `v1.0.0` tag.
- All six archives and all six `.sha256` files are attached to the draft.
- All six SPDX SBOMs are attached and all six archives have verifiable GitHub

- The workflow verified every checksum and embedded CLI version.
