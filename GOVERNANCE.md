# Governance

Open-Dot-Agents is an implementation-neutral open standard. Normative changes
are proposed as numbered RFCs in `spec/rfcs/`, discussed publicly, and accepted
by repository maintainers. An accepted normative change requires updated prose,
schemas, conformance fixtures, generated documentation, and changelog entries.

Release candidates may change incompatibly. Stable major versions follow
Semantic Versioning; incompatible changes require a new major specification.
No single adapter implementation defines portable semantics.
